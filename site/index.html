NarouReader

小説家になろう の小説を、iPhone と Android で読むためのリーダーアプリです。

最新の安定版は次のボタンから直接ダウンロードできます。安定版の Release には Android APK と iOS IPA を両方とも添付しています。

Android 版をダウンロード (APK) iOS 版をダウンロード (IPA)

iOS 版はダウンロードしただけでは iPhone にインストールできません。SideStore または AltStore を使う必要があります。詳しくは下の「iOS (iOS 17.0 以上・iPhone)」の節をご覧ください。

  • これまでの更新履歴

主な機能

  • 本棚管理・読書位置 (しおり) の自動保存と復元・話ごとの既読管理
  • アプリ内リーダーでの本文表示 (フォントサイズ・行間・ダークモードなどの調整)
  • 作品詳細・目次・検索・ランキング・他アプリからの共有受信
  • 連載中の作品の更新チェック
  • バックアップ (JSON ファイルへの書き出しと読み込み)
  • Google アカウントでログインすると、iOS / Android 端末間で本棚・しおり・既読を同期

スクリーンショット

読書画面とランキングの画面です。画像はいずれも Android 版のものです。

インストール方法

Android (Android 8.0 以上)

Android 版をダウンロード (APK)

  1. 「Android 版をダウンロード」のボタンから APK をダウンロードします。
  2. ダウンロードした APK を開くとインストールが始まります。「この提供元からのインストールを許可しますか」の確認が表示された場合は、表示内容を確認して許可すると、インストールが続行します。この許可はアプリの提供元ごとの設定であり、保護機能全体を無効化する必要はありません。
  3. Google Play プロテクトが「未スキャンのアプリ」として確認を求める場合があります。スキャンを求められたら実行し、結果を確認してください。警告やブロックが残る場合は保護機能を無効化・回避せず、取得元と APK を確認し、解決しなければ Issues へ報告してください。表示・判定は端末や時点により異なる場合があります (スキャンを求めずに進む場合もあります)。
  4. 更新は自動では行われません。新しい APK をダウンロードして開くと、本棚・しおり・既読・設定を保持したまま上書き更新されます。アンインストールは不要です。
  5. 更新管理アプリ Obtainium に https://github.com/nunu1733/naroureader を登録すると、新しい安定版の公開時に更新の案内を受け取れます (任意。Obtainium が APK を自動で追跡します)。片方の OS だけが更新された Release でも Android の更新案内が出る場合があります。APK のアプリバージョンが前回と同じ場合は、インストールし直す必要はありません。

iOS (iOS 17.0 以上・iPhone)

iOS 版をダウンロード (IPA)

iOS へのインストールには SideStore または AltStore を使います。通常は Source 経由の利用を推奨します。

  1. SideStore / AltStore をセットアップします。セットアップ方法は各公式サイトを参照してください。
  2. Source https://altstore.xnunux.com/source.json を追加すると、NarouReader のインストールと更新ができます。
  3. 「iOS 版をダウンロード」のボタンから IPA を直接ダウンロードすることもできますが、ダウンロードするだけでは iPhone にインストールできません。署名してインストールする環境 (SideStore / AltStore など) が別途必要です。

同期について

  • アプリ内で Google アカウントにログインすると、同じアカウントでログインした端末間で本棚・しおり・既読が同期されます。iOS / Android をまたいで同期できます。
  • 同期には Google アカウント認証と Firebase のクラウドサービスを使用します。
  • 同期の対象は本棚登録・しおり・既読です。タグ・NG 登録・保存フィルタ・リーダー設定などは端末ごとのローカルデータで、同期されません。
  • Google アカウントでログインしなくても、本棚・読書・検索は利用できます。

このサイトについて

このサイトは NarouReader の配布と案内のためのものです。配布物 (APK / IPA) は GitHub Releases から提供します。アプリのソースコードは公開していません。
