NarouReader

小説家になろう の小説を、iPhone と Android で読むリーダーアプリです。

Android 版をダウンロード (APK) iOS 版をダウンロード (IPA)

iPhone への導入には、SideStore / AltStore の Source から入れるのがおすすめです。手順は下の「iOS」の節をご覧ください。ボタンからダウンロードした IPA は、そのままではインストールできません。

  • これまでの更新履歴

主な機能

  • 本棚管理と、しおり・話ごとの既読の自動保存と復元
  • フォントサイズ・行間・ダークモードを調整できるリーダー
  • 作品検索・ランキング・目次・他アプリからの共有受信のほか、連載中の作品の更新チェック
  • バックアップ (JSON ファイル) と、Google アカウントによる iOS / Android 間の同期

インストール方法

Android (Android 8.0 以上)

Android 版をダウンロード (APK)

  1. ボタンから APK をダウンロードします。
  2. ダウンロードした APK を開くとインストールが始まります。「この提供元からのインストールを許可しますか」の確認が表示された場合は、表示内容を確認して許可すると続行します。この許可は提供元ごとの設定で、保護機能全体を無効化する必要はありません。
  3. Google Play プロテクトからスキャンを求められたら、実行して結果を確認してください。
Play プロテクトの警告が出るとき

「未スキャンのアプリ」として確認を求められることがあります。スキャンを求めずに進む場合もあります。警告やブロックが残る場合は、保護機能を無効化・回避せず、取得元と APK を確認してください。解決しなければ Issues へ報告してください。表示・判定は端末や時点により異なる場合があります。

更新とアンインストールの注意

更新は自動では行われません。新しい APK をダウンロードして開くと、本棚・しおり・既読・設定を保持したまま上書き更新されます。

アンインストールは更新の手順ではありません。アンインストールすると端末内のデータが失われるため、やむを得ず再インストールする場合は、先に設定の「バックアップ / リストア」の「エクスポート」でバックアップを端末外へ保存してください。バックアップは本棚・しおり・既読・タグ・NG 登録・保存フィルタが対象で、リーダー設定は含まれません。インポートフォントを使っている場合は、元のファイルを別途保管してください。

Obtainium で更新を知らせる (任意)

更新管理アプリ Obtainium に https://github.com/nunu1733/naroureader を登録すると、新しい安定版の公開時に更新の案内を受け取れます。片方の OS だけが更新された Release でも Android の更新案内が出る場合があります。APK のアプリバージョンが前回と同じ場合は、インストールし直す必要はありません。

iOS (iOS 17.0 以上・iPhone)

iOS 版をダウンロード (IPA)

iPhone への導入には、SideStore または AltStore の Source 経由がおすすめです。

  1. SideStore / AltStore をセットアップします。セットアップ方法は各公式サイトを参照してください。
  2. Source https://altstore.xnunux.com/source.json を SideStore / AltStore に追加すると、NarouReader のインストールと更新ができます。
IPA を直接ダウンロードする場合

上のボタンから IPA を直接ダウンロードできますが、ダウンロードするだけでは iPhone にインストールできません。署名してインストールする環境 (SideStore / AltStore など) が別途必要です。

同期について

  • アプリ内で Google アカウントにログインすると、同じアカウントでログインした端末間で本棚・しおり・既読が同期されます。iOS / Android をまたいで同期できます。
  • 同期には Google アカウント認証と Firebase のクラウドサービスを使用します。
  • 同期の対象は本棚登録・しおり・既読です。タグ・NG 登録・保存フィルタ・リーダー設定などは端末ごとのローカルデータで、同期されません。
  • Google アカウントでログインしなくても、本棚・読書・検索は利用できます。

このサイトについて

このサイトは NarouReader の配布と案内のためのものです。配布物 (APK / IPA) は GitHub Releases から提供します。アプリのソースコードは公開していません。
